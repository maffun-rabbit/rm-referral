RAKUTEN MOBILE IN JAPAN

申请Rakuten Mobile需要乐天市场账号吗？

申请需要乐天会员账号、乐天ID和密码，但不需要在乐天市场购买商品。

先打开员工介绍优惠 →查看详细说明 ↓

快速结论

  1. 01需要乐天ID和密码。
  2. 02仅注册乐天会员时不需要提交在留卡或护照。
  3. 03不需要乐天市场购物记录。
  4. 04介绍登录和手机申请必须使用同一个乐天ID。

从这里开始

申请前先打开员工介绍链接

为避免错过优惠，请先从员工介绍链接进入，不要先打开普通申请页面。

  1. 打开乐天员工介绍优惠链接。
  2. 使用乐天ID登录；没有ID时先注册新账号。
  3. 使用同一个乐天ID继续申请Rakuten Mobile。
  4. 确认并完成活动页面显示的最新条件。

官方FAQ说明，仅从普通页面申请不会自动适用员工介绍活动，必须通过乐天员工发送的URL完成介绍登录。

PRACTICAL GUIDE

乐天会员与乐天市场不是同一个概念

  • ✓
    乐天会员是乐天各项服务通用的账号。
  • ✓
    乐天市场是使用同一ID的购物服务；购物并不是办理手机合约的条件。
  • ✓
    请只使用一个乐天ID，多个账号可能导致登录或积分发放问题。

PRACTICAL GUIDE

最稳妥的办理顺序

  • ✓
    首先打开员工介绍链接。
  • ✓
    使用现有乐天ID登录；没有ID时选择新会员注册。
  • ✓
    姓名、出生日期和地址应与之后用于实名认证的证件完全一致。
  • ✓
    使用同一账号继续申请Rakuten Mobile。证件是在办理手机合约时需要，而不是仅注册乐天会员时需要。

PRACTICAL GUIDE

需要单独创建ID时

  • ✓
    在新标签页打开乐天会员官方注册页面，创建账号后回到员工介绍链接，先完成介绍登录再申请。
  • ✓
    确保可以接收验证邮件，并妥善保存密码。
  • ✓
    如果自行办理困难，可以到Rakuten Mobile官方门店咨询ID注册和申请流程。
