RAKUTEN MOBILE IN JAPAN

Do You Need a Rakuten Ichiba Account to Apply for Rakuten Mobile?

You need a free Rakuten membership to obtain a Rakuten ID and password. You do not need to buy anything on Rakuten Ichiba.

Open the employee referral offer first →Read the guide ↓

Quick answer

  1. 01A Rakuten ID and password are required.
  2. 02No residence card or passport is needed just to create the membership account.
  3. 03No Rakuten Ichiba purchase history is required.
  4. 04Use the same Rakuten ID for referral login and the mobile application.

START HERE

Open the employee referral link before applying

To avoid missing the offer, begin with the employee referral link—not a separate application page.

  1. Open the Rakuten employee referral offer.
  2. Sign in with your Rakuten ID, or create one if needed.
  3. Apply for Rakuten Mobile using the same Rakuten ID.
  4. Check and complete the current campaign conditions.

The official FAQ states that simply applying from a normal page does not activate this employee referral. Referral login through the URL sent by a Rakuten employee is required.

PRACTICAL GUIDE

Rakuten membership and Rakuten Ichiba are different

  • ✓
    Rakuten membership is the common account used across Rakuten services.
  • ✓
    Rakuten Ichiba is an online shopping service that uses the same ID; buying something there is not an application requirement.
  • ✓
    Create only one Rakuten ID. Multiple accounts can cause login and point-crediting problems.

PRACTICAL GUIDE

The safest order

  • ✓
    Open the employee referral link first.
  • ✓
    Sign in with your current Rakuten ID or choose new member registration.
  • ✓
    Enter your name, birth date and address exactly as shown on the identity document you will use later.
  • ✓
    Continue the mobile application with the same account. Identity documents are required during the mobile contract process, not merely to create the Rakuten account.

PRACTICAL GUIDE

If you need to prepare the ID separately

  • ✓
    Open the official Rakuten membership registration page in a new tab, create the account, then return to the employee referral link and log in before applying.
  • ✓
    Keep access to the email address used for verification and store the password safely.
  • ✓
    If self-service is difficult, an official Rakuten Mobile shop may help with Rakuten ID creation and the application.
