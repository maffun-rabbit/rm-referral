# 関東ショップページ Astro移行・公開記録

## 公開範囲

日本語版の関東7都県にあるショップページを、既存URLと本文を維持したままAstroの共通テンプレートへ移行した。

| 都県 | ページ数 |
| --- | ---: |
| 茨城 | 131 |
| 栃木 | 86 |
| 群馬 | 89 |
| 埼玉 | 294 |
| 千葉 | 264 |
| 東京 | 587 |
| 神奈川 | 341 |
| **合計** | **1,792** |

今回新たに移行したのは、東京都を除く6県の1,205ページ。

## 実装

- 都県・キャリア・ショップを扱う汎用動的ルートへ変更
- 共通ヘッダーの都県リンクと表示名をページデータから生成
- ヘッダー、CTA、フッターをAstroの共通コンポーネントとして維持
- 都県トップ、通信エリアページ、トップ、サイトマップ、robots.txtは従来版を維持
- 日本語Workersへの公開時は、関東のショップページだけをAstro出力で差し替える

## 検証結果

- Astro生成: 1,794ページ（ショップ1,792＋検証用2）
- 自動テスト: 15件合格、失敗0件
- canonical: 1,792件すべて一意で出力URLと一致
- サイトマップ収録: 1,792件すべて確認
- JSON-LD、内部リンク、CTA、ヘッダー、フッター: 全件合格
- 公開用HTML総数: 7,955件を維持
- 通信エリアページ: 関東7都県277件を維持
- 本番代表6ページ: Astro出力と公開HTMLのSHA-256が一致
- 都県トップ: HTTP 200
- サイトマップ: HTTP 200
- `.wrangler` 内部キャッシュファイル: HTTP 404
