# 工程1：中国語サイトの現状棚卸しと移行範囲

## 対象

- 言語: 简体中文（`zh-CN`）
- 現行ソース: `zh/`
- 現行Worker: `rm-referral-zh`
- 現行公開URL: `https://rm-referral-zh.maffun.workers.dev/`
- 移行後URL: `https://mnp-navi.jp/zh/`
- Astroソース: `astro-site/`

## ページ内訳

| 種別 | 件数 |
|---|---:|
| トップ | 1 |
| 都道府県 | 47 |
| ショップ | 6,714 |
| エリアカバレッジ | 53 |
| ガイド・トピック | 19 |
| 合計 | 6,834 |

サイトマップにも6,834 URLが収録されている。

## 現行成果物の基準値

`node scripts/build-language.mjs zh`を実行し、Astroオーバーレイなしの現行中国語成果物が正常に生成されることを確認した。

- 言語別成果物: 6,858ファイル
- HTML: 6,848ファイル
- 公開対象HTML: 6,834ページ
- Astroオーバーレイ: 0件
- 現行ソース容量: 約125MB
- 生成成果物容量: 約126MB
- 公開トップ: HTTP 200
- 公開サイトマップ: HTTP 200、6,834 URL

HTML数と公開ページ数の差には、公開対象外のGoogle確認ファイルと、後述の空ファイル13件が含まれる。

## 現行SEO URL

現行HTMLのcanonical、hreflang、構造化データ、内部リンク、robots.txt、サイトマップは、主に`rm-referral-zh.maffun.workers.dev`を参照している。移行時に次へ統一する。

- canonical: `https://mnp-navi.jp/zh/...`
- 内部リンク・静的アセット: `/zh/...`
- sitemap: `https://mnp-navi.jp/zh/sitemap.xml`
- 公開ルート: `mnp-navi.jp/zh/*`

## 翻訳と表示上の確認事項

- トップ、都道府県、ショップ、ガイド本文は簡体字中国語で作成済み。
- 店舗の日本語正式名称は`lang="ja"`で併記しており、意図した表示として維持する。
- 一部の都道府県ページに、日本語の検索0件メッセージなどUI残存がある。
- 共通UI用の中国語辞書は既に存在するが、旧HTML置換辞書は未整備。
- 現行トップには日本語サイトのWorkers URLを直接参照するリンクが残っている。

## 保留されていた13ファイル

`zh/kanagawa/au/`配下にステージ済みの`index 2.html`が13件ある。全件0バイトで、同じディレクトリには内容のある正規`index.html`が存在する。

工程1では既存状態を保持した。工程2で、Astro移行とは無関係な空の重複ファイルとして削除し、正規ページを維持する方針とする。

## 移行方針

英語版で完成した多言語共通基盤を再利用し、次の順序で進める。

1. 中国語辞書と共通ローダーを整備する。
2. 中国語6,834ページをAstroルートへ接続する。
3. SEO、内部リンク、翻訳残存、構造化データを全件検証する。
4. 検証用WorkerでPC・スマートフォン・検索操作を確認する。
5. `mnp-navi.jp/zh/*`へ本番接続する。
6. Google Search Consoleへ中国語サイトマップを送信する。

日本語・ベトナム語・英語の既存ルートと成果物は変更しない。

## 次工程

工程2では、中国語UI辞書と旧HTML置換処理を整備し、共通ローダーが中国語の全ページ種別を読み込める状態にする。併せて0バイトの重複ファイル13件を整理する。
