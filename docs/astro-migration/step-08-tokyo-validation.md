# 工程8：東京都全件のビルド・リンク・サイトマップ検証

- サイトマップ収録済みの対象ページ: 587件

## 全ページで確認した項目

- titleとdescriptionが存在する
- canonicalが生成パスと一致する
- robotsが `index, follow` になっている
- canonicalが重複していない
- `lang="ja"` が設定されている
- JSON-LDが2件あり、JSONとして解析できる
- WebPage構造化データのURLと言語が正しい
- BreadcrumbListの終点がcanonicalと一致する
- ID属性が重複していない
- ページ内リンクのリンク先IDが存在する
- 紹介CTAが3件あり、共通紹介URLを使用している
- ヘッダーとフッターが各1件だけ存在する

## サイトマップ

現行 `sitemap.xml` に東京都587ショップのcanonicalがすべて収録されているため、URL追加や301リダイレクトは不要。`/vi-component-preview/` などの検証専用URLはサイトマップに含まれていない。Astroの検証用 `dist/index.html` は本番トップと同じパスになるため、工程9のデプロイ対象から必ず除外する。

## 移行範囲外の内部リンク

各ショップページから参照する `/` と `/tokyo/` は、今回の東京都ショップ移行範囲には含めず、現行サイト側のページを維持する。工程9では現行日本語サイト一式を土台にし、東京都587ショップだけをAstro出力で差し替えるオーバーレイ方式にする必要がある。これにより、トップ、都道府県ページ、通信エリアページ、サイトマップ、robots.txtを失わずに段階公開できる。
