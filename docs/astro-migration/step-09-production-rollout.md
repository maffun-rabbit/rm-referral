# 工程9：日本語Workersへの段階公開

## 公開範囲

- 対象: 日本語Workers `rm-referral`
- Astroへ切り替えた範囲: 東京都のショップ587ページ
- 維持した範囲: 日本語トップ、東京トップ、通信エリア54ページ、他道府県、ガイド、サイトマップ、robots.txt
- 変更していないWorkers: 英語、中国語、韓国語、ベトナム語、ポルトガル語

## デプロイ方式

現行日本語サイトを `.deploy/ja` に複製し、`astro-site/dist/tokyo/` のキャリア別ショップディレクトリだけを上書きするオーバーレイ方式を採用した。Astroの検証用トップとベトナム語検証ページは公開対象外。

- Astro版東京都ショップ: 587件

- トップページ保全: 成功

## 公開時の修正

初回デプロイログでローカルの `.wrangler/cache` が静的資産へ含まれていることを検知した。`.wrangler` を準備処理と `.assetsignore` の双方で除外し、公開用コピーに存在しないことを確認して再デプロイした。該当URLは公開後に404を確認済み。
