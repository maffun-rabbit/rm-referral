# 工程2：中国語辞書と多言語共通基盤

## 実施内容

英語版で整備した多言語共通ローダーと共通Astroコンポーネントへ、中国語を接続した。

- 中国語UI置換辞書を追加
- 中国語用ローダー`load-chinese-pages.ts`を追加
- 47都道府県、6,714ショップ、53エリアカバレッジ、19ガイドの読み込みを確認
- Workers URLを`https://mnp-navi.jp/zh/`へ変換
- 内部アセットと内部リンクを`/zh/`配下へ変換
- 共通ヘッダー、CTA、フッターの中国語辞書を継続利用

## 主なUI置換

- 通信会社で絞り込む → 按运营商筛选
- 検索0件メッセージ → 没有符合条件的门店。请更换搜索词或运营商。
- オンラインで乗り換えを始める → 在线开始携号转网
- 紹介キャンペーンを確認する → 查看推荐活动条件
- 情報確認日 → 信息确认日期
