北海道から東海までの移行分と合わせ、日本語版のAstroショップページは5,079ページになった。

## 実装と保護範囲

- 既存の都道府県・キャリア・ショップ共通ルートへ近畿6府県を追加
- 共通ヘッダー、CTA、フッターをAstroコンポーネントから生成
- 既存URL、本文、canonical、構造化データを維持
- 日本語トップ、府県トップ、通信エリアページ、サイトマップ、robots.txtは従来版を維持
- 日本語Workersでは移行済みショップページだけをAstro出力で差し替え

## 検証結果

- Astro生成: 5,081ページ（ショップ5,079＋検証用2）
- 自動テスト: 24件合格、失敗0件

- 公開用HTML総数: 7,955件を維持
- 移行済み30都道府県の通信エリアページ: 870件を維持
- 近畿6府県の本番代表ページ: Astro出力と公開HTMLのSHA-256が一致
- 大阪府トップ: HTTP 200
- サイトマップ: HTTP 200
- `.wrangler` 内部キャッシュファイル: HTTP 404
