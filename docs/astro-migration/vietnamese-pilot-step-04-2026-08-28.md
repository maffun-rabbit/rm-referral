# 工程4：ベトナム語パイロット移行

## 対象ページ

- ベトナム語トップ: `/vi/`
- ベトナム語東京都トップ: `/vi/tokyo/`
- 代表ショップ: `/vi/tokyo/au/au-shop-narimasu/`

## 実施内容

- 3ページをAstroの静的生成対象へ追加した。
- 既存のベトナム語本文をビルドデータとして読み込み、内容を落とさずAstro共通レイアウトへ移した。
- canonical、`hreflang`、OG URL、構造化データを `https://mnp-navi.jp/vi/` 配下へ統一した。
- 旧 `*.maffun.workers.dev` の内部URLを、新しい `mnp-navi.jp` の言語別URLへ変換した。
- CSS、JavaScript、内部リンクを `/vi/` 配下へ揃えた。
- ヘッダーとフッターをベトナム語共通辞書から生成した。
- 代表ショップの通常CTA、最終CTA、追従CTAを共通コンポーネントへ置き換えた。
- 東京都トップに残っていた検索UI、未該当メッセージ、最終案内の日本語をベトナム語へ修正した。
- 店舗の正式名称は読み手が現地で照合できるよう、翻訳名と併記する `lang="ja"` の日本語表記を維持した。

## 段階移行方式

現時点では既存ベトナム語HTMLを正本としてAstroが読み込み、共通部分とURLをAstro側で制御する。今後は同じローダーとコンポーネントを全ページへ横展開できる。

言語別ビルド時は、既存ベトナム語サイトを `.deploy/vi/vi/` へ格納した後、Astroで生成したページだけを同一パスへ上書きする。未移行ページを欠落させず、ページ単位で順次Astroへ切り替えられる。

## 検証結果

- Astro静的生成: **6,719ページ成功**（既存6,716ページ＋ベトナム語3ページ）
- 既存日本語ショップ: **6,714ページの回帰検査成功**
- 自動テスト: **36件中36件成功**
- ベトナム語3ページについて、canonical、7種類の`hreflang`、内部URL、CSS・JavaScript、共通パーツ、既知の日本語UI残存を検査した。
- ベトナム語Worker成果物: **6,852ファイル、HTML 6,835件**
- Astro上書き: **3ファイルが生成物と完全一致**

## この工程で変更していないもの

- Cloudflareへの本番デプロイ
- `mnp-navi.jp/vi/*` のWorkerルート
- DNS設定
- 既存公開サイト
