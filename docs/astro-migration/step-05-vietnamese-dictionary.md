# 工程5：ベトナム語辞書の追加

## 実施内容

- `src/i18n/vi.ts` にベトナム語の共通UI辞書を追加した。
- `src/config/site.ts` にベトナム語WorkersのURLを登録した。
- 共通コンポーネントの `locale="vi"` 指定により、ヘッダー、CTA、フッターをベトナム語で出力できるようにした。
- 日付ラベルの区切り記号も辞書へ移し、日本語では `：`、ベトナム語では `: ` を使用するようにした。
- 既存ベトナム語ページの表現を基準にしながら、最終CTAはコンポーネント構造に合う自然な表現へ整えた。

## 辞書化した範囲

- HTML言語属性とOGPロケール
- サイト名とヘッダーリンク
- キャンペーン名、対象者、ポイント表記
- 通常・最終・追従CTAの文言
- キャンペーン注意書きと情報確認日
- フッターの運営者表記と紹介リンク表記

ショップ固有のタイトル、本文、パンくず、住所、周辺店舗などは共通UI辞書とは分離したままにしている。

## 検証結果

- 検証ページ: `astro-site/dist/vi-component-preview/index.html`
- `lang="vi"` と `og:locale="vi_VN"` を確認。
- 共通ヘッダー、3種類のCTA、フッターのベトナム語出力を確認。
- 3種類のCTAが共通の紹介URLを使用していることを確認。
- 自動テスト: 8件成功、失敗0件。
- 検証ページは `noindex, nofollow`、GA4無効。
- 現行ベトナム語HTMLと本番環境は変更・公開していない。
