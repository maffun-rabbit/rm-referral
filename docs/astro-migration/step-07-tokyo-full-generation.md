# 工程7：東京都ショップページの全件生成

## 実施内容

- 東京都の既存ショップページを移行用データとして読み込むローダーを追加した。
- 動的ルート `src/pages/tokyo/[carrier]/[slug]/index.astro` を追加した。
- 全ショップに共通するページ構造を `JapaneseShopPage.astro` へ集約した。
- ヘッダー、フッター、通常CTA、最終CTA、追従CTAは共通コンポーネントから生成する。
- ショップ固有のSEO情報、構造化データ、本文、店舗情報、地域トピック、周辺店舗情報を各ページへ引き継いだ。
- 市区町村の通信エリアページ `tokyo/coverage/` はショップページではないため、今回の生成対象から除外した。

## 移行中のデータの扱い

この段階では、ショップ固有の本文を欠落させずに移すため、既存の東京都HTMLを移行用データソースとして読み込んでいる。共通ヘッダー・CTA・フッターは旧HTMLから再利用せず、Astroコンポーネントで置き換えている。そのため、共通パーツの変更は1か所で東京都587ページへ反映できる。

## 影響範囲

- 現行の東京都HTML、本番Workers、サイトマップは変更していない。
- 既存の未追跡 `index 2.html` 13件は変更していない。
