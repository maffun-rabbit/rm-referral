# 工程5：ベトナム語47都道府県トップ移行

## 実施内容

- ベトナム語版の47都道府県トップをすべてAstroの静的生成対象へ移した。
- 東京都以外の46ページを1つの動的Astroルートから生成し、工程4で移行済みの東京都トップと合わせて47ページを管理する構成にした。
- 都道府県ごとのタイトル、説明文、本文、店舗一覧は既存ベトナム語ページから欠落なく引き継いだ。
- canonical、`hreflang`、OG URL、構造化データを `https://mnp-navi.jp/vi/<都道府県>/` へ統一した。
- CSS、JavaScript、都道府県間・ショップへの内部リンクを `/vi/` 配下へ統一した。
- 店舗検索・通信会社フィルター・検索結果なし表示・最終案内に残っていた日本語UIをベトナム語へ統一した。
- 店舗の正式名称は、日本で実際の看板や公式ページと照合できるよう `lang="ja"` の日本語併記を維持した。
- ベトナム語サイトマップとrobots.txtをAstro管理へ移し、旧Workersドメインを `https://mnp-navi.jp/vi/` に置き換えた。

## 検証結果

- Astro静的生成: **6,765ページ成功**
- ベトナム語都道府県トップ: **47件中47件生成成功**
- 既存日本語ショップ: **6,714ページの回帰検査成功**
- 自動テスト: **38件中38件成功**
- ベトナム語サイトマップ: **6,834 URL**、重複なし、全URLが `https://mnp-navi.jp/vi/` 配下
- 47都道府県トップがすべてサイトマップに含まれることを確認した。
- ベトナム語Worker成果物: **6,852ファイル、HTML 6,835件**
- Astro上書き対象: **51ファイルが生成物と完全一致**

## この工程で変更していないもの

- Cloudflareへの本番デプロイ
- `mnp-navi.jp/vi/*` のWorkerルート
- DNS設定
- 現在公開中のベトナム語サイト
