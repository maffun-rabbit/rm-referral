RAKUTEN MOBILE IN JAPAN

É preciso ter conta no Rakuten Ichiba para contratar o Rakuten Mobile?

Você precisa do cadastro gratuito de membro Rakuten para obter um Rakuten ID e senha. Não é necessário comprar no Rakuten Ichiba.

Abrir primeiro a indicação →Ler o guia ↓

Resposta rápida

  1. 01Rakuten ID e senha são necessários.
  2. 02Não é preciso apresentar Zairyu Card ou passaporte apenas para criar a conta Rakuten.
  3. 03Não é necessário ter histórico de compras no Rakuten Ichiba.
  4. 04Use o mesmo Rakuten ID no login da indicação e na solicitação da linha.

COMECE AQUI

Abra o link de indicação de funcionário antes de solicitar

Para não perder o benefício, comece pelo link de indicação de funcionário, e não por uma página comum de solicitação.

  1. Abra a oferta de indicação de funcionário da Rakuten.
  2. Entre com seu Rakuten ID ou crie uma conta se necessário.
  3. Solicite o Rakuten Mobile usando o mesmo Rakuten ID.
  4. Confira e cumpra as condições atuais da campanha.

O FAQ oficial informa que iniciar por uma página comum não ativa automaticamente a indicação. É necessário fazer o login pelo URL enviado por um funcionário da Rakuten.

PRACTICAL GUIDE

Cadastro Rakuten e Rakuten Ichiba são coisas diferentes

  • ✓
    O cadastro Rakuten é a conta comum usada nos serviços do grupo.
  • ✓
    Rakuten Ichiba é a loja online que usa o mesmo ID; fazer compras não é requisito para o contrato móvel.
  • ✓
    Use apenas um Rakuten ID. Várias contas podem causar problemas de login e crédito dos pontos.

PRACTICAL GUIDE

A ordem mais segura

  • ✓
    Abra primeiro o link de indicação de funcionário.
  • ✓
    Entre com o Rakuten ID atual ou selecione o cadastro de novo membro.
  • ✓
    Digite nome, data de nascimento e endereço exatamente como no documento que será usado depois.
  • ✓
    Continue a solicitação do Rakuten Mobile com a mesma conta. Os documentos são exigidos no contrato móvel, não apenas para criar a conta Rakuten.

PRACTICAL GUIDE

Se precisar criar o ID separadamente

  • ✓
    Abra a página oficial de cadastro Rakuten em uma nova aba, crie a conta e volte ao link de indicação para entrar antes de solicitar.
  • ✓
    Use um e-mail que receba o código de verificação e guarde a senha com segurança.
  • ✓
    Se for difícil fazer sozinho, uma loja oficial Rakuten Mobile pode orientar a criação do ID e a solicitação.
