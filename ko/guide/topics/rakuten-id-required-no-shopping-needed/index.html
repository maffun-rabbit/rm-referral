Rakuten Mobile 신청에 Rakuten Ichiba 계정이 필요한가요?

Rakuten ID와 비밀번호를 받기 위해 무료 Rakuten 회원 가입이 필요하지만 Rakuten Ichiba 구매 이력은 필요하지 않습니다.

직원 추천 혜택 먼저 열기 →자세한 안내 보기 ↓

빠른 결론

  1. 01Rakuten ID와 비밀번호가 필요합니다.
  2. 02Rakuten 회원 계정만 만들 때는 재류카드나 여권을 제출하지 않습니다.
  3. 03Rakuten Ichiba 구매 이력은 필요하지 않습니다.
  4. 04추천 로그인과 모바일 신청에 동일한 Rakuten ID를 사용하세요.

여기서 시작

신청 전에 직원 추천 링크를 먼저 여세요

혜택을 놓치지 않으려면 일반 신청 페이지가 아니라 직원 추천 링크에서 시작하세요.

  1. Rakuten 직원 추천 혜택 링크를 엽니다.
  2. Rakuten ID로 로그인하고, ID가 없으면 새로 만듭니다.
  3. 동일한 Rakuten ID로 Rakuten Mobile을 신청합니다.
  4. 캠페인 페이지의 최신 조건을 확인하고 완료합니다.

공식 FAQ에 따르면 일반 페이지에서 신청하는 것만으로는 직원 추천 혜택이 적용되지 않으며, Rakuten 직원이 보낸 URL에서 추천 로그인이 필요합니다.

PRACTICAL GUIDE

Rakuten 회원과 Rakuten Ichiba는 다릅니다

  • ✓
    Rakuten 회원은 여러 Rakuten 서비스에서 공통으로 사용하는 계정입니다.
  • ✓
    Rakuten Ichiba는 같은 ID를 사용하는 쇼핑 서비스이며, 상품 구매는 모바일 계약 조건이 아닙니다.
  • ✓
    Rakuten ID는 하나만 사용하세요. 여러 계정은 로그인이나 포인트 지급 문제를 일으킬 수 있습니다.

PRACTICAL GUIDE

안전한 신청 순서

  • ✓
    직원 추천 링크를 먼저 엽니다.
  • ✓
    기존 Rakuten ID로 로그인하고, 없으면 신규 회원 등록을 선택합니다.
  • ✓
    이름, 생년월일, 주소를 나중에 본인 확인에 사용할 서류와 정확히 같게 입력합니다.
  • ✓
    같은 계정으로 Rakuten Mobile 신청을 계속합니다. 본인 확인 서류는 회원 계정 생성 단계가 아니라 모바일 계약 단계에서 필요합니다.

PRACTICAL GUIDE

ID를 별도로 준비해야 할 때

  • ✓
    Rakuten 회원 공식 등록 페이지를 새 탭에서 열어 계정을 만든 다음 직원 추천 링크로 돌아와 신청 전에 로그인하세요.
  • ✓
    인증 메일을 받을 수 있는 주소를 사용하고 비밀번호를 안전하게 보관하세요.
  • ✓
    혼자 진행하기 어렵다면 공식 Rakuten Mobile 매장에서 ID 생성과 신청 절차를 안내받을 수 있습니다.
