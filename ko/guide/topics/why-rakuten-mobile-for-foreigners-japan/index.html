RAKUTEN MOBILE IN JAPAN

Rakuten Mobile이 일본 거주 외국인에게 잘 맞는 이유

장점은 저렴한 요금만이 아닙니다. 매월 비용을 예측하기 쉽고 일본 번호를 유지하며 해외에서도 기본 데이터를 사용할 수 있습니다.

빠른 결론

  1. 01직원 추천을 통한 해당 MNP는 최대 14,000 Rakuten 기간 한정 포인트를 받을 수 있습니다.
  2. 02국내 데이터는 20GB를 넘어도 월 최대 3,278엔입니다.
  3. 03100개 이상의 지원 국가·지역에서 매월 고속 해외 로밍 2GB가 포함됩니다.
  4. 04Rakuten Link로 대부분의 일본 휴대전화·유선전화에 무료 통화할 수 있지만 제외 번호가 있습니다.
  5. 05온라인 신청이 어렵다면 가까운 Rakuten Mobile 매장을 찾을 수 있습니다.

여기서 시작

신청 전에 직원 추천 링크를 먼저 여세요

혜택을 놓치지 않으려면 일반 신청 페이지가 아니라 직원 추천 링크에서 시작하세요.

  1. Rakuten 직원 추천 혜택 링크를 엽니다.
  2. Rakuten ID로 로그인하고, ID가 없으면 새로 만듭니다.
  3. 동일한 Rakuten ID로 Rakuten Mobile을 신청합니다.
  4. 캠페인 페이지의 최신 조건을 확인하고 완료합니다.

공식 FAQ에 따르면 일반 페이지에서 신청하는 것만으로는 직원 추천 혜택이 적용되지 않으며, Rakuten 직원이 보낸 URL에서 추천 로그인이 필요합니다.

PRACTICAL GUIDE

일본 생활에서 체감하기 쉬운 장점

  • ✓
    3GB까지 1,078엔, 3GB 초과 20GB까지 2,178엔, 20GB 초과는 3,278엔이며 모두 세금 포함 월 요금입니다.
  • ✓
    MNP가 완료되면 현재 사용 중인 일본 전화번호를 계속 사용할 수 있습니다.
  • ✓
    변경 전에 집, 직장, 자주 이용하는 이동 경로의 통신 가능 지역을 확인하세요.

PRACTICAL GUIDE

직원 추천 혜택의 의미

  • ✓
    신청 전에 직원 추천 링크를 열고 전 과정에서 동일한 Rakuten ID를 사용하세요.
  • ✓
    현재 직원 추천 조건에서 해당 MNP는 최대 14,000포인트이며 현금이 아닌 기간 한정 Rakuten 포인트입니다.
  • ✓
    금액, 기간, 대상 조건은 변경될 수 있으므로 추천 로그인 후 표시되는 캠페인 페이지를 확인하세요.

PRACTICAL GUIDE

해외여행에서도 유용

  • ✓
    100개 이상의 지원 국가·지역에서 매월 고속 로밍 데이터 2GB가 포함됩니다.
  • ✓
    도착 직후 지도, 메시지, 차량 호출에 유용하지만 해외 무제한 데이터는 아닙니다.
  • ✓
    출국 전에 일본에서 Rakuten Link를 인증하고 해외 로밍 설정을 확인하세요.

PRACTICAL GUIDE

일본어 절차가 어려울 때

  • ✓
    이 사이트는 중요한 일본어 버튼과 용어를 한국어로 설명합니다.
  • ✓
    본인 확인이 반복해서 실패하면 이름, 주소, 서류 유효기간, 사진 품질을 확인하세요.
  • ✓
    매장에서 절차 안내를 받을 수 있지만 특정 외국어 지원은 보장되지 않습니다.
